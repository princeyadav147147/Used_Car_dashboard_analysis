# 🚗 Used Car Dashboard Analysis

A comprehensive data analysis and visualization project for analyzing used car market trends, pricing patterns, and predictive analytics.

## 📋 Project Overview

This project combines data science, machine learning, and interactive dashboards to provide insights into the used automotive market. It includes predictive modeling for car valuations and an interactive Power BI dashboard for market analysis.

## 📁 Project Structure

```
Used_Car_dashboard_analysis/
├── README.md                                          # Project documentation
├── car_pridiction.ipynb                              # Jupyter notebook with ML models & analysis
├── autos_dashboard.pbip                              # Power BI dashboard file
├── Automotive Sales & Market Analysis Report.docx    # Detailed analysis report
```

## 🎯 Key Features

- **Predictive Analytics**: Machine learning models for car price prediction
- **Interactive Dashboard**: Power BI visualization for market trends
- **Comprehensive Analysis**: Detailed automotive market insights
- **Data-Driven Insights**: Market trends and pricing patterns

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook
- Power BI Desktop (optional, for dashboard viewing)
- Required Python libraries: pandas, numpy, scikit-learn, matplotlib, seaborn

### Installation

1. Clone the repository
```bash
git clone https://github.com/princeyadav147147/Used_Car_dashboard_analysis.git
cd Used_Car_dashboard_analysis
```

2. Install required packages
```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

3. Run the Jupyter Notebook
```bash
jupyter notebook car_pridiction.ipynb
```

4. View the Power BI Dashboard
- Open `autos_dashboard.pbip` in Power BI Desktop

## 📖 Usage

1. **For Data Analysis**: Open and run the Jupyter notebook `car_pridiction.ipynb` to explore the data and see ML models in action.

2. **For Dashboards**: Open `autos_dashboard.pbip` in Power BI to interact with visualizations.

3. **For Detailed Report**: Review `Automotive Sales & Market Analysis Report.docx` for comprehensive findings.

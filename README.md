# 🚗 Used Car Dashboard Analysis

A comprehensive data analysis and visualization project for analyzing used car market trends, pricing patterns, and predictive analytics.

## 📋 Project Overview

This project combines data analysis, and interactive dashboards to provide insights into the used automotive market. It includes predictive modeling for car valuations and an interactive Power BI dashboard to explore trends in pricing, demand, and vehicle performance.

## 📁 Project Structure

```
Used_Car_dashboard_analysis/
├── README.md                                          # Project documentation
├── car_pridiction.ipynb                              # Jupyter notebook & analysis
├── autos_dashboard.pbip                              # Power BI dashboard project for used car insights
├── Automotive Market & Sales Analysis Report (Complete).docx  # Detailed analysis report
```

## 🎯 Key Features

- **Data cleaning**: using Python & pandas to clean and structure the used car dataset
- **Interactive Dashboard**: Power BI visualization for market trends and price analysis
- **Comprehensive Analysis**: Detailed automotive market insights
- **Data-Driven Insights**: Market trends and pricing patterns
- **Predictive Modeling**: Used car valuation and pricing estimation

### `car_pridiction.ipynb`

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook
- Power BI Desktop (optional, for dashboard viewing)
- Required Python libraries: pandas, numpy, scikit-learn, matplotlib, seaborn, jupyter

### Installation

1. Clone the repository
```bash
git clone https://github.com/princeyadav147147/Used_Car_dashboard_analysis.git
cd Used_Car_dashboard_analysis
```

2. Install required packages
```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

3. Run the Jupyter Notebook
```bash
jupyter notebook car_pridiction.ipynb
```

4. View the Power BI Dashboard
- Open `autos_dashboard.pbip` in Power BI Desktop to explore the interactive dashboard.

## 📖 Usage

1. **For Data Analysis**: Open and run the Jupyter notebook `car_pridiction.ipynb` to explore the data and see ML models in action.

2. **For Dashboards**: Open `autos_dashboard.pbip` in Power BI to interact with visualizations.

3. **For Detailed Report**: Review `Automotive Market & Sales Analysis Report (Complete).docx` for comprehensive findings.
